# 功能边界与使用

## 部署应用

Nginx、Apache、MySQL、Redis、PHP 8.2–8.5 使用面板固定版本运行时，可与其他版本并存，网站或数据库绑定按实例保存。Docker Manager 提供真实容器、镜像、网络、卷及受限 Compose 生命周期。

MongoDB、Memcached、Elasticsearch、phpMyAdmin、RabbitMQ、OpenLiteSpeed 使用固定镜像与回环端口。持久应用使用命名卷，删除应用不会自动销毁卷。MongoDB、RabbitMQ、OpenLiteSpeed 访问凭据由密码学随机数生成，管理员通过带 CSRF 的凭据接口读取，响应禁止缓存。phpMyAdmin 提供原版数据库管理界面，需要通过回环端口转发访问，并连接网络可达且已授权的数据库；不自动修改原有数据库的公网监听策略。Elasticsearch 单节点示例无集群 SLA，只有回环入口，不能直接公开它的未认证 API。

PHP 5.2–8.1 使用独立 PHP FastCGI 后端、Nginx 前端和网站数据卷。PHP 5.2 使用历史 FastCGI/FPM 补丁，SAPI 显示 `cgi-fcgi`；其他版本显示 `fpm-fcgi`。通过“文件同步”填写来源网站与目标 Compose 项目 ID 上传文件；可在 Docker Manager 中绑定网站域名。PHP 后端无外网出口，禁用进程执行函数，主机网站目录不会挂载进去。历史扩展或应用依赖仍需单独迁移验证；架构只声明已经完成真实验收的 amd64。停止维护版本不会因为安装验收通过而得到安全维护。

Pure-FTPd 提供实际 FTPS、虚拟账号、网站 chroot 与上传下载，默认回环 2121 和被动端口 30000–30049，不自动开放公网。内置本地自签名证书；远程使用需要自行配置可信证书和受控入口。PM2 Manager 使用真实 PM2 7.0.4、固定 JS 入口、专用网站 UID 和 systemd 启停重启/开机恢复，不暴露任意 root Shell；npm 依赖锁定并禁用安装脚本。

## 专业功能

| 功能 | 当前实际实现 |
| --- | --- |
| 网站诊断 | DNS、实际 HTTP、TLS 证书、Nginx 配置与网站目录检查 |
| 网络威胁检测 | 实际监听端口/连接、端口基线、新增监听告警、Fail2ban 状态；不是抓包式 IDS |
| 网站分析、网站统计 v2 | 实际 Nginx JSON 日志的 PV/IP、状态、错误、小时趋势、路径、爬虫、来源；有界读取末尾 16 MiB，报告注明截断，不代表全历史数据仓库 |
| 文件同步 | 网站到网站或隔离 PHP 环境的增量复制、SHA-256、冲突保护、逐文件检查点；不删除目标、不提供任意远程 root 同步 |
| 每日报告 | 实际资源、站点、失败任务、流量、安全、证书到期摘要，每日自动持久化；暂无短信/邮件推送 |
| Nginx WAF | URI/参数/方法/扫描器过滤、单 IP 限速、事件与配置回滚 |
| Apache WAF | 受管虚拟主机请求 URI/参数/方法/扫描器过滤、语法校验与回滚；不是完整 ModSecurity CRS，不解析所有请求体 |
| 企业防篡改 | HMAC 签名基线、内容备份、变更/权限检查、分钟级自动恢复基线已有文件、恢复前留存；不是内核实时写拦截，不自动删除新增文件 |
| 网站防篡改 | 签名基线、变更检查、手动恢复已有备份文件、网站级策略 |
| 文件监控 | 有界哈希基线、权限/内容变化、排除规则、持久化定时检查；不是每个写入事件的内核审计 |
| 负载均衡 | Nginx 加权轮询、备用节点、IP 粘滞、TCP 探测、连接错误转移，默认回环入口；不是多节点控制平面 |
| 移动端 | 响应式 PWA、现有登录/TOTP、Service Worker 离线提示，不缓存认证页面/API/凭据；不是原生 iOS/Android 安装包 |
| PHP 代码安全 | 固定规则静态扫描，高风险函数、编码混淆、反序列化/文件写入证据行号；不是完整 PHP AST/污点分析，不保证发现所有后门 |
| 任务管理器 | 实际 `/proc` CPU/内存与连接、PID/启动身份核对、pidfd 终止受管非 root 进程；拒绝 PID1、root 和非受管进程 |
| 用户管理 | admin/operator/viewer、网站权限范围、账户更新、会话撤销、最后管理员保护，复用现有 TOTP |
| 系统加固 | 固定 sysctl 基线、实际值校验、卸载恢复；不擅自改 SSH 用户或关闭网络 |
| 磁盘分析 | 网站目录大小、文件数量、大文件排行、有界扫描；不自动删除文件，不宣称全磁盘历史趋势 |
| 防入侵 | Debian Fail2ban 的 SSHD Jail、配置与服务检查、封禁查询和审计解封 |
| 多主机运维 | HTTPS 只读健康聚合、加密凭据保存、令牌签发/撤销；不是远程 root 命令分发，最多 12 主机 |
| NFS 管理 | 实际 NFSv4 挂载/卸载、ro/rw、nosuid/nodev/noexec、systemd 开机恢复、活跃挂载卸载保护 |

## 验收口径

`ready` 指上面列出的实际实现、安装处理器与相应 Linux 功能验收通过。审批自动允许只省去操作批准，并不会把测试失败改成通过。测试失败必须修正重跑。

新功能的真实验收环境是外置硬盘上的 Debian 13 amd64 隔离虚拟机；基础原生运行时另在现有 Debian amd64 验收机复核。公共验收摘要不包含密码、令牌、签名私钥或客户网站内容。源码单测、浏览器验证、隔离 Linux 功能验证与真实公网生产验证不是同一件事。本仓库不宣称已在所有生产服务器、发行版或 CPU 上全面验收。
