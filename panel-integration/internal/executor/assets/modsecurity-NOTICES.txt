CloudStack modifications, 2026-10-11:

- The pinned release's shipped generated configure script tests actual fork

  This is an exact generated-release patch, not a host-autoconf regeneration.

Audit/body/debug logging is disabled by the managed engine configuration.
Request bodies, matched values, headers, authentication cookies, form values
and client addresses are not included in these managed WAF events. Ordinary
website/server logs are independently configured and are not covered by that
claim. An enabled native engine is not a guarantee against every attack.
